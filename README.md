# Gideon Anosike — Portfolio

A modern, vibrant single-page portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Contact form

The `/api/contact` route sends messages with Resend. Add `RESEND_API_KEY` to the Vercel project or a local `.env.local` file. The sending domain `codergidingz.xyz` must remain verified in Resend.
